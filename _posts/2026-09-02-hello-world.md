New site, who dis. This blog is built with [Jekyll](https://jekyllrb.com)
and styled with [terminal.css](https://terminalcss.xyz), hosted for free on
GitHub Pages.

<!--more-->

## Writing a post

Create a file in `_posts/` named `YYYY-MM-DD-some-title.md`:

```markdown
---
title: "My new post"
tags: [notes]
---

Write in **Markdown**. That's it.
```

Push to `main` and GitHub Pages rebuilds the site in about a minute.
